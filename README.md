# ❤️ Heart Disease Prediction Model

##  Overview

This project is a **Machine Learning-based Heart Disease Prediction System** that predicts whether a person is likely to have heart disease based on medical attributes.

The goal is to assist in early detection and provide insights using data-driven models.

---

##Features

* Predicts heart disease risk (Yes/No)
* Uses supervised learning algorithms
* Data preprocessing & feature engineering included
* Model evaluation with accuracy metrics
* Simple and scalable pipeline

---

##  Dataset

The dataset contains medical attributes such as:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol Level
* Fasting Blood Sugar
* ECG Results
* Maximum Heart Rate
* Exercise Induced Angina
* Oldpeak (ST depression)

---

## Machine Learning Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)

## 📌 How to Run


# Clone repository
git clone https://github.com/your-username/heart-disease-prediction.git

# Navigate to project
cd heart-disease-prediction

# Install dependencies
pip install -r requirements.txt

# Run the model
python app.py   # or main.py
